# 微信小程序打包与提审说明

## 一、打包

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序，拿到 AppID。
2. 把 AppID 填进 `src/manifest.json` 的 `mp-weixin.appid`。
3. 运行：

   ```bash
   npm ci
   npm run build:mp-weixin
   ```

   这一步会依次生成签文数据、编译小程序，并检查包体（`scripts/check-mp-size.mjs`）。
   输出在 `dist/build/mp-weixin`。
4. 用微信开发者工具导入 `dist/build/mp-weixin`，真机预览后点「上传」。

### 包体

- 微信主包上限 2MB。目前约 1.5MB，最大的是签文数据 `utils/qian.js`（约 920KB，六位神明 520 签）。
- 超过 1.8MB 时构建会提醒，超过 2MB 会直接报错。再加神明或签文前，先把签文按神明拆进分包。

### 需要在真机上确认的地方

开发环境里没法跑微信真机，下面几项请在开发者工具和真机上各看一遍：

- 神明像、香炉等 SVG 图片能正常显示。SVG 里的入场动画在小程序 `<image>` 里可能不播放，金色描边圈可能不显示，人物本身应该正常。
- 摇手机求签（加速度计）在真机上能触发；开发者工具里点「摇签」按钮即可。
- 音效能正常播放，首页右上角可以关掉。
- 「签卡」在小程序里不画神明像（小程序 canvas 不能画 SVG），其余文字和版式正常，保存到相册需要用户授权。

## 二、隐私与权限

- 所有记录（生日、求签历史、香火簿、心愿）只存在手机本地（`uni.setStorageSync`），没有服务器，不上传任何数据。
- 用到的需授权接口只有「保存图片到相册」（`saveImageToPhotosAlbum`）。在公众平台「设置 → 服务内容声明 → 用户隐私保护指引」里勾选「相册（仅写入）」，用途写「保存签卡图片」。
- 不需要获取用户昵称、头像、手机号、位置。

## 三、审核风险（提审前请先看）

微信官方「常见拒绝情形」第 3.2.4 条写明，小程序页面中不能有测试类内容，举例就是「算命、抽签、星座运势」。第 3.2.8.7 条还禁止「宣扬封建迷信」。
来源：<https://developers.weixin.qq.com/miniprogram/product/reject.html>

本项目的核心玩法就是掷筊、抽签和每日运势，**按这条规则大概率会被拒**。改几个字眼不能改变功能本身，也不建议用伪装的方式过审：即使过了，后续巡查下架的风险也一样存在。

可以考虑的方向：

1. **以网页版为主**：H5 已经可以通过 GitHub Pages 访问，不受小程序审核限制。
2. **调整小程序的定位和内容**：把小程序做成「传统签诗与民俗文化」的阅读类产品，例如签诗全文浏览、逐句白话、典故故事、黄历节气，去掉随机抽签和吉凶运势。这样功能和描述是一致的，但体验和现在差别很大。
3. **个人主体限制**：「宗教信息」类目需要《互联网宗教信息服务许可证》，而且只对企业等非个人主体开放。个人主体的可选类目里没有合适的一项。

无论选哪个方向，页面里已有的免责声明（「仅供娱乐与传统文化体验」）都要保留。
